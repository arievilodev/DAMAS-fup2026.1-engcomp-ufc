# Linhas para compilação e execução

#### Em diretório `Damas/`

## Compilação
```bash
make ALL
```
ou
```bash
mingw32-make ALL
```
(varia de acordo com a instalação local)

## Execução
```bash
./damas
```
ou
```bash
./damas exemplo.txt
```

## Limpar
usando rm
```bash
make clean
```
ou
usando del, geralmente Windows
```bash
mingw32-make clean_win
```
(a utilização de make ou mingw32-make depende da instalação local)
